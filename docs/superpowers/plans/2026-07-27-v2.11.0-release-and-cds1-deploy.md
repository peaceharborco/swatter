# Swatter v2.11.0 — Release and cds1 Deploy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v2.11.0 — which makes an already-live permanent-ban ladder safer — to cds1, then gate the widening of its window from 7 to 30 days.

**Architecture:** The temp→perm recidivism ladder has run on cds1 since v1.0.0 at ~5.37 perms/day. This release adds an abort lever (`REPEAT_ENABLE`), closes a queue-based bypass of that lever, fixes a live ban-path defect, and builds the operator tooling the abort path assumes but does not have. Deployment is staged across four gates so each change is independently revertible.

**Tech Stack:** Bash 4+, gawk, sqlite3, CSF, Cloudflare API. Tests are plain bash scripts under `test/`, run by `make test`.

## Global Constraints

- **Every task ends with `make test` green (rc=0).** The suite is the release gate — `install/release.sh` refuses to tag otherwise.
- **Mutation-check every load-bearing predicate.** Four review rounds on the escalation work found defects a green suite had already passed. A test is not trusted until mutating the line it guards makes it fail.
- **Ban-path changes require a Grok pass before the tag** (Tasks 2, 4). Per `~/Developer/CLAUDE.md`: `~/.grok/bin/grok -p "<brief>" --always-approve --sandbox read-only --max-turns 40`.
- **Commit email must stay `142285318+peaceharborco@users.noreply.github.com`** — this repo is public.
- **`REPEAT_ENABLE` has exactly one definition**, `: "${REPEAT_ENABLE:=true}"` in `lib/common.sh`. No read site may use its own `:-` default; a stray `:-false` silently disarms every upgrade.
- **Never raise `PERM_RATE_ALERT_*` to create headroom.** Those knobs are the alarm floor, not an abort threshold.
- **No cds1 changes until Task 12.** Tasks 1–11 are local.

### Task 2: Disarming must refuse queued perm intents it cannot clear

**Files:**
- Modify: `lib/score.sh` (`_swatter_retry_pending`, the row loop ~`:386-435`)

**Interfaces:**
- Consumes: `REPEAT_ENABLE` from Task 1.
- Produces: no new functions. Behavior contract — while `REPEAT_ENABLE != true`, the drain does not apply a queued `action='perm'` unless its reason positively identifies a non-ladder origin (`honeypot`).

**Why an allowlist, not a `recidivism=` filter:** cds1 runs v2.10.0, which does not write the `recidivism=` stamp. Every ladder perm queued *today* lacks it, so filtering on that substring would let exactly the rows we must stop through. We therefore refuse any queued perm we cannot prove is non-ladder. Rows are **left queued, not cleared**, and their attempt counter is not bumped — pausing must not destroy intent. The abort path clears them explicitly via Task 3.

```bash
# swatter pending [--drain-perms] [--dry-run] — inspect or drain the durable
# retry queue. Exists because the abort path needs it: disarming the ladder
# HOLDS queued perms (lib/score.sh) but does not clear them, and without this
# an operator's only option was hand-SQL against pending_blocks.
cmd_pending() {
    local drain=0 dry=0
    while [[ $# -gt 0 ]]; do
        case "$1" in
            --drain-perms) drain=1; shift ;;
            --dry-run)     dry=1;   shift ;;
            *) die "usage: swatter pending [--drain-perms] [--dry-run]" ;;
        esac
    done
    swatter_store_init
    local rows; rows="$(swatter_store_pending_list)"
    if [[ -z "$rows" ]]; then echo "pending: queue is empty"; return 0; fi
    printf '%-18s %-8s %-6s %5s  %s\n' "IP" "PLANE" "ACTION" "ATT" "REASON"
    local ip plane action ttl folded rep ff attempts audit reason rest
    while IFS=$'\t' read -r ip plane action ttl folded rep ff attempts audit reason rest; do
        printf '%-18s %-8s %-6s %5s  %s\n' "$ip" "$plane" "$action" "$attempts" "$reason"
    done <<< "$rows"
    (( drain )) || return 0
    local n=0
    while IFS=$'\t' read -r ip plane action ttl folded rep ff attempts audit reason rest; do
        [[ "$action" == "perm" ]] || continue
        n=$(( n + 1 ))
        (( dry )) && continue
        swatter_store_pending_clear "$ip" "$plane"
    done <<< "$rows"
    if (( dry )); then
        echo "pending: would clear ${n} queued perm intent(s) (--dry-run)"
    else
        echo "pending: cleared ${n} queued perm intent(s)"
    fi
}
```
